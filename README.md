# ALETHA releases

Disk images of ALETHA for Mac. ALETHA.app checks here for a newer version and updates itself; each image is signed, and the app installs only what checks out with its built-in key.

Apple silicon: `ALETHA-<version>-apple-silicon.dmg` · Intel: `ALETHA-<version>-intel.dmg` · macOS 14 or newer.
